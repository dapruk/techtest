## Run locally 

Requires Node.js 24.

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Run with Docker

```bash
docker compose up -d --build
```

Open [http://localhost:3000](http://localhost:3000).

Stop the container with:

```bash
docker compose down
```
